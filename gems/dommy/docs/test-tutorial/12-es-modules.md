# 12. ES module / import map

> 執筆予定。

## module スクリプト

- `<script type="module">` の扱い

## import map による名前解決

- `<script type="importmap">` で bare specifier を解決する

## どこまで再現するか

- CSS import は空 module として扱われる
- 未ビルドの dev server を完全再現するものではなく、bundle 済み asset や fixture を基本にする
