# 14. トラブルシュート

> 執筆予定。

## JS が動かないとき

- バックエンド未登録 / script が解決できない / `execute_scripts: false`

## 非同期がすれ違うとき

- 自動 microtask drain と `settle` / `advance_time` の違い、進め忘れ

## エラーとログを読む

- strict エラーの読み方、`js_errors` / `console` の確認

## debug で今の DOM を調べる

- `debug.dom_summary` / `debug.buttons` / `debug.forms` / `debug.aria_snapshot`
